# Contribuindo

Obrigado por considerar uma contribuição.

## Preparação

1. Faça um fork e crie um branch a partir de `main`.
2. Use Node.js 22.5 ou mais recente.
3. Execute `npm install`.
4. Copie apenas os arquivos `.example` para criar sua configuração local.

Nunca inclua cookies, IDs de destinatários, endpoints privados, bancos SQLite ou dados coletados em commits, issues ou pull requests.

## Antes do pull request

```bash
npm run ci
```

Inclua testes para mudanças de comportamento. Prefira commits pequenos e mensagens que expliquem o objetivo da alteração. No pull request, descreva o problema, a solução e como ela foi validada.
